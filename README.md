# MojMajstor – Service Marketplace Web Application

A team-based web application developed as part of a university software engineering project at the University of Belgrade, School of Electrical Engineering.

MojMajstor is a platform designed to connect customers with service professionals, making it easier to find workers, submit service requests, and communicate.

## Key Features
- User registration and authentication
- Different user roles for customers and service professionals
- Service request creation and management
- Messaging between users
- Notifications and request status tracking
- Form validation and error handling

## Technologies
- Python
- Django
- MySQL
- HTML, CSS, JavaScript
- Selenium
- Git
